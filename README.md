# PPT 设计规范（极简・专业・学术）

## 1. 整体风格
- 保持极简、专业、学术表达。
- 页面元素精简，避免无关装饰。

## 2. 背景
- 使用纯白或浅灰背景，确保图表与文字清晰可读。
- 避免使用图片背景、渐变背景或深色背景。

## 3. 配色
- 主色仅选 1 种（建议校徽色或沉稳深蓝）。
- 搭配灰、黑、白，总色彩不超过 3 种。
- 建议：标题使用主色，正文使用黑色/深灰，注释使用浅灰。

## 4. 字体
- 中文：无衬线字体（如微软雅黑、思源黑体）。
- 英文：Arial 或 Helvetica。
- 全篇最多使用 2 种字体。
- 标题可加粗；正文字号不小于 18pt；标题字号建议 28–36pt。

## 5. 布局
- 严格遵循对齐原则。
- 可使用 PPT 自带参考线或 iSlide 参考线辅助对齐。
- 合理留白，避免页面过满。
